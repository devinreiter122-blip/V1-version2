# Jar ohne Installation bauen (GitHub)
1. Kostenloses Konto auf github.com, dann "New repository" (z. B. v1mod).
2. "uploading an existing file": ALLE Dateien und Ordner aus diesem Projekt hineinziehen
   (auch den versteckten Ordner .github) und "Commit changes" klicken.
3. Reiter "Actions" -> der Build "Build mod" läuft (ca. 3-5 Minuten).
4. Auf den fertigen Lauf klicken -> unten bei "Artifacts" die Datei "v1mod-jar" herunterladen.
   Darin liegt v1mod-2.0.0.jar.
5. In der CurseForge-App: Profil für Minecraft 1.21.1 mit NeoForge erstellen,
   dann die .jar per "Open Folder" -> "mods" hineinlegen.
